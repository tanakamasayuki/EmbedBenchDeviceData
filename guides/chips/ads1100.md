# ADS1100 — 電源基準の 16bit 差動 ΔΣ ADC（アドレス工場固定）

> 差動入力 1 チャンネルの ΔΣ ADC。基準電圧が電源そのものなので、測れるのは「電源に対する比」で
> あって絶対電圧ではない。設定レジスタは 1 バイトだけで、アドレス指定のレジスタマップを持たない。
>
> **確度**: Texas Instruments の datasheet
> [SBAS239B](https://www.ti.com/lit/ds/symlink/ads1100.pdf)（2002-05 初版 / 2003-11 改訂 Rev.B）に基づく。
> 本文の数値・ビット定義・転送の形はすべてこの文書由来で、**ライブラリ実装から補った箇所は無い**。
> 実測での確認はしていない（`observations/ads1100/` は未取得）。

## これは何か

TI の 6 ピン（SOT23-6）ΔΣ A/D コンバータ。差動入力が 1 組（VIN+ / VIN−）、PGA、内蔵クロック、
I2C インタフェースだけで構成される。**外付け部品は電源のバイパスコンデンサと I2C プルアップだけで
動く**のが売りで、ブリッジセンサやサーミスタのような低インピーダンス差動源をそのまま繋ぐことを
想定している。

できること:

- 差動電圧を 16bit（8SPS 時）で読む。データレートを上げると分解能が落ちる（16 / 15 / 14 / 12 bit）。
- PGA で 1 / 2 / 4 / 8 倍に増幅する。フルスケールは `±VDD / PGA`。
- 連続変換と単発変換を選べる。単発では変換後に自動でパワーダウンする（0.05µA typ）。
- オフセットとゲインの自己校正が常時走る。ユーザ操作は不要で、**無効化もできない**。

できないこと・持っていないもの:

- **絶対電圧が測れない。** 基準電圧は VDD そのもの（ratiometric）。VDD が 5.00V か 4.85V かで
  同じ入力が別のコードになる。絶対値が要るなら内蔵 2.048V 基準を持つ [ADS1110](ads1110.md) か、
  内蔵基準と PGA を持つ [ADS1115](ads1115.md) を使う。
- **I2C アドレスを変えられない。** `0x48`–`0x4F` は型番サフィックス（ADS1100A0〜A7）で工場固定。
  ピンでもレジスタでも変更できない。同一バスに載せられるのは最大 8 個。
- **割り込み線・DRDY ピンが無い。** 6 ピンのうち 2 本が I2C、2 本が電源、2 本が入力で、余りが無い。
  変換完了はポーリングで知るしかない。
- **「新しいデータかどうか」が判定できない。** 単発モードなら ST/BSY で変換中か否かは分かるが、
  連続モードでは ST/BSY は常に 1 を返す（[ADS1110](ads1110.md) の ST/DRDY のような既読フラグは無い）。
- 負電圧を入力できない。VIN+ / VIN− はいずれも `GND − 0.2V` 〜 `VDD + 0.2V` の範囲。
  差動としては双極性の信号を読めるが、どちらのピンも GND を割ってはいけない。
- マルチプレクサが無い。チャンネルは 1 組だけ。
- コンパレータ・しきい値レジスタが無い。

## レジスタ / コマンド

**アドレス指定のレジスタは存在しない。** ポインタバイトを送る仕組みが無く、書けば設定レジスタ、
読めば出力レジスタ＋設定レジスタが返る、という固定の形になっている
（datasheet §REGISTERS, p.9）。

| 方向 | 長さ | 中身 |
|---|---|---|
| 書き込み | 1 バイト | 設定レジスタ。**2 バイト目以降は無視され、ACK も返らない** |
| 読み出し | 3 バイト | byte0 = 出力レジスタ MSB、byte1 = 出力レジスタ LSB、byte2 = 設定レジスタ |
| 読み出し（短縮） | 2 バイト | 出力レジスタだけ読んで止めてよい |
| 読み出し（超過） | 4 バイト目以降 | 常に `0xFF` |

### 出力レジスタ（読み出しのみ、16bit）

- 2 の補数、MSB first。
- **右詰め・符号拡張**される。つまり 12bit（128SPS）でも 16bit の変数にそのまま入り、
  16bit アキュムレータで平均を取れる。ただし取り得る範囲は狭まる（下表）。
- リセット/電源投入直後は `0x0000`。最初の変換が終わるまで 0 が返る。

| データレート | ビット数 | 最小コード | 最大コード | 負フルスケール | 正フルスケール |
|---|---|---|---|---|---|
| 8SPS | 16 | −32768 | 32767 | `0x8000` | `0x7FFF` |
| 16SPS | 15 | −16384 | 16383 | `0xC000` | `0x3FFF` |
| 32SPS | 14 | −8192 | 8191 | `0xE000` | `0x1FFF` |
| 128SPS | 12 | −2048 | 2047 | `0xF800` | `0x07FF` |

電圧への換算（datasheet p.6 の式）:

```
Code = −MinCode × PGA × (VIN+ − VIN−) / VDD
```

つまり `(VIN+ − VIN−) = Code × VDD / (−MinCode × PGA)`。8SPS・PGA=1・VDD=5V なら
1LSB = 5V / 32768 ≒ 152.6µV。**VDD が式に入っている**ことを忘れない。

### 設定レジスタ（読み書き 1 バイト、既定値 `0x8C`）

| bit | 名前 | 意味 |
|---|---|---|
| 7 | ST/BSY | **書き**: 単発モードで `1` を書くと変換開始（`0` は無効。連続モードでは無視）。**読み**: 単発モードで `1`=変換中 / `0`=完了して結果あり。**連続モードでは常に `1`** |
| 6-5 | — | 予約。**必ず `0` を書く** |
| 4 | SC | `0`=連続変換（既定） / `1`=単発変換 |
| 3-2 | DR1:DR0 | `00`=128SPS / `01`=32SPS / `10`=16SPS / `11`=8SPS（既定） |
| 1-0 | PGA1:PGA0 | `00`=×1（既定） / `01`=×2 / `10`=×4 / `11`=×8 |

既定値 `0x8C` = `1000_1100` → 連続変換、8SPS、PGA=1。

### そのほかのバス上の振る舞い

- **General Call Reset に応答する**。アドレスバイト `0x00` + データバイト `0x06` で電源投入直後と
  同じ状態に戻る（変換中なら中断、出力レジスタ 0、設定レジスタ既定値）。`0x00` は常に ACK するが、
  データバイトは `0x04` と `0x06` 以外 ACK しない。
- **Hs モード（3.4MHz）は明示的な起動が要る**。START の後に Hs master code `00001xxx` を送る
  （このバイトは ACK されない）。次の STOP で Hs モードを抜ける。

## 典型的な使い方

1. **電源を確認する。** 変換結果が VDD で割られるので、VDD を実測しておかないと電圧値にならない。
   比だけで良い用途（ブリッジ、分圧比）なら不要。
2. **アドレスを確認する。** 型番サフィックスがそのままアドレス。手元の個体が A0 か A3 かは
   パッケージのマーキング（`AD0`〜`AD7`）で判る（datasheet p.8）。分からなければ `0x48`–`0x4F` を scan する。
3. **設定レジスタに 1 バイト書く。** 例: 単発・8SPS・PGA=1 で変換開始なら `0x9C`
   （ST/BSY=1, SC=1, DR=11, PGA=00）。
4. **待つ。** 8SPS なら typ 125ms、最悪 154ms。内蔵発振器なので固定値で待つなら最悪値を使う。
5. **3 バイト読む。** 先頭 2 バイトが結果（MSB first）、3 バイト目が設定レジスタ。
   単発モードなら 3 バイト目の bit7 が `0` になっていることが変換完了の確認になる。
6. 連続変換で使う場合は 3 を SC=0 で書くだけでよく、以後は 2 バイト読むだけ。
   ただし**同じ値が返っても「新しい変換結果」か判断できない**ので、データレートより遅い周期で読む。

## 利用上の注意

- **基準は電源。絶対電圧計にはならない。** レギュレータのドリフト・ノイズがそのまま測定値に乗る。
  電源を測定対象と共有する比率測定（ブリッジ、ポテンショメータ）でこそ真価が出る構成である。
- **アドレスは変えられない。** `0x48` は本リポジトリ内だけでも
  [`ads1110`](ads1110.md) / [`ads1115`](ads1115.md) / `ina226` / `m5stack-mcu-u198` (Unit Step16) が
  名乗り得る。同じバスに複数の Unit ADC は挿せず、A1〜A7 の別型番を手配するしかない。
- **書き込みは 1 バイトきり。** 2 バイト目以降は ACK もされない。多くの I2C ライブラリは
  「レジスタアドレス + 値」の 2 バイト書き込みを標準にしているので、そのまま呼ぶと 2 バイト目が
  落ちて意図しない設定になる。**必ず 1 バイトだけ送る**。
- **読み出しは 3 バイト固定順で、順番を選べない。** 設定レジスタだけ読むことはできず、
  必ず出力レジスタ 2 バイトを先に受け取る。4 バイト目以降は `0xFF` なので、
  長めに読むと `0xFF` がゴミとして混ざる。
- **連続モードでは ST/BSY が判定に使えない。** 常に `1` を読む。データ更新の検出手段は無いので、
  ホスト側で時間管理する。「変換が終わったか」を知りたいなら単発モードを使う。
- **リセット直後は `0x0000` が返る。** 最初の変換が完了するまで 0 なので、
  電源投入直後の 1 回目を「暗い / 入力 0V」と誤読しないこと。8SPS なら最悪 154ms かかる。
- **General Call の巻き添えに注意。** バス上の他のデバイスに general call reset (`0x00`,`0x06`) を
  投げると ADS1100 も設定ごとリセットされる。
- **入力インピーダンスが低い。** 差動 2.4MΩ/PGA。PGA=8 なら 300kΩ まで下がる。
  高出力インピーダンスのセンサを直結すると分圧されて誤差になる。
- **アンチエイリアスは自前で。** 内蔵デジタルフィルタは sinc¹ で、データレートの半分を超える
  成分は折り返す。RC 一段でよいので入れる（datasheet p.7 ALIASING）。
- **400kHz は datasheet 上は問題ない**（Fast mode 対応、Table III のタイミングが規定されている）が、
  本リポジトリでは未実測。`scenarios/ads1100/p0.yaml` は 100kHz と 400kHz の両方を試す設定になっている。
- **Unit ADC (U013) の入力回路は datasheet の範囲外。** ユニット基板側の分圧・保護回路が
  何をしているかは M5Stack の製品ページを見る必要がある。チップのフルスケール `±VDD/PGA` が
  そのままコネクタの入力レンジになるとは限らない。

## 出典と確度

- レジスタ定義・転送長・タイミング・電気的特性: すべて TI datasheet SBAS239B（Rev.B, 2003-11）。
  [`chips/ads1100.yaml`](../../chips/ads1100.yaml) の `datasheets:` に記録された版と一致する。
- [`profiles/ads1100.yaml`](https://github.com/tanakamasayuki/I2CDeviceDB/blob/38f1d82/profiles/ads1100.yaml) は `evidence.source: datasheet` /
  `confidence: tentative`。`transport.write_len: 1` / `read_len: 3` /
  `read_layout: "2 data bytes msb-first, then the configuration byte"` は上記 p.10 の記述そのもの。
- **未確認**: 実機キャプチャが無い。ACK の返り方、`0xFF` パディングの実際、400kHz での動作、
  General Call への応答は確かめられていない。
- **未調査**: [`scenarios/ads1100/p0.yaml`](https://github.com/tanakamasayuki/I2CDeviceDB/blob/38f1d82/scenarios/ads1100/p0.yaml) は read-only で、
  device-detection / conversion-read / config-byte-read しか行わない。
  ゲイン掃引・データレート掃引・単発変換のトリガ（設定レジスタへの書き込み）は `deferred` に置かれている。
- **datasheet が答えていないこと**: Unit ADC (U013) 基板側の入力レンジ・分圧比・保護回路。
  これはチップの仕様ではなく M5Stack の回路の話で、製品ページを見るしかない。
