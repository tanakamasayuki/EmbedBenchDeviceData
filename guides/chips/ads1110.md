# ADS1110 — 内蔵 2.048V 基準付き 16bit 差動 ΔΣ ADC（アドレス工場固定）

> [ADS1100](ads1100.md) の基準電圧を電源から内蔵 2.048V に置き換えた版。フルスケールが
> `±2.048V / PGA` に固定されるので、**電源電圧に依存しない絶対電圧が測れる**。設定は 1 バイト、
> アドレス指定のレジスタマップは持たない。
>
> **確度**: Texas Instruments の datasheet
> [SBAS276A](https://www.ti.com/lit/ds/symlink/ads1110.pdf)（2003-03 初版 / 2003-11 改訂 Rev.A）に基づく。
> 本文の数値・ビット定義・転送の形はすべてこの文書由来で、**ライブラリ実装から補った箇所は無い**。
> 実測での確認はしていない（`observations/ads1110/` は未取得）。

## これは何か

TI の 6 ピン（SOT23-6）ΔΣ A/D コンバータ。差動入力 1 組、PGA、**2.048V の内蔵基準**、内蔵発振器、
I2C インタフェースが 1 パッケージに入っている。ADS1100 との違いは基準電圧だけで、
ピン配置・転送の形・設定レジスタのビット割り当ては同一である
（データレートの値とビット 7 の読み出し意味だけが違う）。

できること:

- 差動電圧を 16bit（15SPS 時）で読む。データレートを上げると分解能が落ちる（16 / 15 / 14 / 12 bit）。
- PGA で 1 / 2 / 4 / 8 倍。フルスケールは `±2.048V / PGA`（FSR = 4.096V/PGA）。
- 連続変換と単発変換。単発では変換後に自動でパワーダウンする（0.05µA typ）。
- **ST/DRDY による「未読データか」の判定**。ADS1100 に無いこの 1 ビットが実用上いちばん大きい差。
- オフセット・ゲインの自己校正が常時走る。無効化はできない。

できないこと・持っていないもの:

- **I2C アドレスを変えられない。** `0x48`–`0x4F` は型番サフィックス（ADS1110A0〜A7）で工場固定。
  ピンでもレジスタでも変更できない。同一バスに載せられるのは最大 8 個。
- **内蔵基準を外に出せない・外部基準を入れられない。** 2.048V は測定にも使えず、単体の仕様値も無い
  （ゲイン誤差・ドリフトの規格に丸め込まれている）。
- **割り込み線・DRDY ピンが無い。** ST/DRDY は「ピン」ではなくレジスタのビットである。
  変換完了はポーリングで知る。
- 負電圧を入力できない。VIN+ / VIN− は `GND − 0.2V` 〜 `VDD + 0.2V`。datasheet は
  **−200mV より下に振らないこと**と明記している（Table 2 脚注, p.7）。
- マルチプレクサが無い。チャンネルは 1 組だけ。
- コンパレータ・しきい値レジスタが無い。
- 電源 5V でも測れるのは ±2.048V まで。それ以上は外部で分圧するしかない。

## レジスタ / コマンド

**アドレス指定のレジスタは存在しない。** 書けば設定レジスタ、読めば出力レジスタ＋設定レジスタが
返る固定の形（datasheet §REGISTERS, p.10）。

| 方向 | 長さ | 中身 |
|---|---|---|
| 書き込み | 1 バイト | 設定レジスタ。**2 バイト目以降は無視され、ACK も返らない** |
| 読み出し | 3 バイト | byte0 = 出力レジスタ MSB、byte1 = 出力レジスタ LSB、byte2 = 設定レジスタ |
| 読み出し（短縮） | 2 バイト | 出力レジスタだけ読んで止めてよい |
| 読み出し（超過） | 4 バイト目以降 | 常に `0xFF` |

### 出力レジスタ（読み出しのみ、16bit）

- 2 の補数、MSB first、右詰め・符号拡張。
- リセット/電源投入直後は `0x0000`。最初の変換が終わるまで 0 が返る。

| データレート | ビット数 | 最小コード | 最大コード | −2.048V | +2.048V |
|---|---|---|---|---|---|
| 15SPS | 16 | −32768 | 32767 | `0x8000` | `0x7FFF` |
| 30SPS | 15 | −16384 | 16383 | `0xC000` | `0x3FFF` |
| 60SPS | 14 | −8192 | 8191 | `0xE000` | `0x1FFF` |
| 240SPS | 12 | −2048 | 2047 | `0xF800` | `0x07FF` |

電圧への換算（datasheet p.6 の式）:

```
Code = −MinCode × PGA × (VIN+ − VIN−) / 2.048V
```

15SPS・PGA=1 なら 1LSB = 2.048V / 32768 = 62.5µV。**VDD は式に入らない**。

### 設定レジスタ（読み書き 1 バイト、既定値 `0x8C`）

| bit | 名前 | 意味 |
|---|---|---|
| 7 | ST/DRDY | **書き**: 単発モードで `1` を書くと変換開始（`0` は無効。連続モードでは無視）。**読み**: `0`=直前に読んだ出力レジスタの値は未読の新しいデータ / `1`=既に読まれた古いデータ |
| 6-5 | — | 予約。**必ず `0` を書く** |
| 4 | SC | `0`=連続変換（既定） / `1`=単発変換 |
| 3-2 | DR1:DR0 | `00`=240SPS / `01`=60SPS / `10`=30SPS / `11`=15SPS（既定） |
| 1-0 | PGA1:PGA0 | `00`=×1（既定） / `01`=×2 / `10`=×4 / `11`=×8 |

既定値 `0x8C` = `1000_1100` → 連続変換、15SPS、PGA=1。

**ST/DRDY の読み出し意味は ADS1100 の ST/BSY と違う。** ADS1110 では:

- 変換結果を出力レジスタに書き込むとき、チップが ST/DRDY を `0` にする。
- **設定レジスタのいずれかのビットが読まれると `1` に戻る**（読み取りで消費される）。
- 返る値は「いま読んだ出力レジスタの内容」に対する既読フラグであって、次に読む値の話ではない。
  出力レジスタが先、設定レジスタが後に返ってくる順序と対応している（datasheet p.11）。

### そのほかのバス上の振る舞い

- **General Call Reset に応答する**。アドレスバイト `0x00` + データバイト `0x06` で電源投入直後と
  同じ状態に戻る。`0x00` は常に ACK するが、データバイトは `0x04` と `0x06` 以外 ACK しない。
- **Hs モード（3.4MHz）は明示的な起動が要る**。START の後に Hs master code `00001xxx` を送る
  （ACK されない）。次の STOP で抜ける。

## 典型的な使い方

1. **アドレスを確認する。** 型番サフィックスがそのままアドレス。パッケージのマーキングは
   `ED0`〜`ED7`（datasheet p.9）。分からなければ `0x48`–`0x4F` を scan する。
2. **設定レジスタに 1 バイト書く。** 例: 単発・15SPS・PGA=1 で変換開始なら `0x9C`
   （ST/DRDY=1, SC=1, DR=11, PGA=00）。
3. **待つ。** 15SPS なら typ 67ms、最悪 91ms。内蔵発振器なので固定待ちなら最悪値を使う。
4. **3 バイト読む。** 先頭 2 バイトが結果（MSB first）、3 バイト目が設定レジスタ。
   3 バイト目の bit7 が `0` なら、いま読んだ 2 バイトは新しい変換結果である。`1` なら
   まだ変換が終わっていない（単発モード）か、既に読んだ値である（連続モード）。
5. 連続変換なら 2 を SC=0 で書き、以後は 3 バイト読み続ける。**ST/DRDY が `0` のときだけ
   採用する**ことで、同じ値を二重に数えずに済む。
6. 電圧に直す: `V = Code × 2.048 / (−MinCode × PGA)`。データレートによって MinCode が変わる
   ことに注意（上表）。

## 利用上の注意

- **ST/DRDY は読み取りで消費される。** 設定レジスタを読むと `1` に戻る。3 バイト読みを 2 か所から
  行うと片方が「新しいデータ」を取りこぼす。読む場所は 1 か所に決める。
  出力レジスタだけ 2 バイトで読む分には ST/DRDY は変化しない。
- **ST/DRDY のフラグは「いま読んだ値」に対するもの。** 3 バイト読みの中で先に出力レジスタが
  返り、あとから設定レジスタが返る。「次の読み出しが新しいか」を示すのではない。
- **フルスケールは電源に依存しない代わりに、電源より狭い。** VDD=5V でも ±2.048V までしか測れない。
  5V 系の信号を測るには外部で分圧するか、`±6.144V` レンジを持つ [ADS1115](ads1115.md) を使う。
- **入力を −200mV 以下に振らない。** datasheet が Table 2 の脚注で明示している。
  差動としては双極性を読めるが、どちらのピンも GND を大きく割ってはいけない。
- **アドレスは変えられない。** `0x48` は本リポジトリ内だけでも
  [`ads1100`](ads1100.md) / [`ads1115`](ads1115.md) / `ina226` / `m5stack-mcu-u198` (Unit Step16) が
  名乗り得る。同じバスに複数の Unit ADC v1.1 は挿せない。
- **書き込みは 1 バイトきり。** 2 バイト目以降は ACK もされない。「レジスタアドレス + 値」の
  2 バイト書き込みを標準にしている I2C ライブラリをそのまま使うと 2 バイト目が落ちる。
- **読み出しは 3 バイト固定順。** 設定レジスタだけ読むことはできない。4 バイト目以降は `0xFF`。
- **リセット直後は `0x0000` が返る。** 最初の変換が完了するまで 0。15SPS なら最悪 91ms かかる。
- **General Call の巻き添えに注意。** 他のデバイス向けの general call reset (`0x00`,`0x06`) で
  ADS1110 も設定ごとリセットされる。
- **PGA を上げるとコモンモード入力インピーダンスが下がる。** PGA=8 で 0.9MΩ。
  高出力インピーダンスのセンサでは分圧誤差になる。
- **アンチエイリアスは自前で。** 内蔵デジタルフィルタは sinc¹。データレートの半分を超える成分は折り返す。
- **400kHz は datasheet 上は問題ない**（Fast mode 対応、Table 3 にタイミング規格がある）が、
  本リポジトリでは未実測。`scenarios/ads1110/p0.yaml` は 100kHz と 400kHz を試す設定になっている。
- **Unit ADC v1.1 (U013-V11) の入力回路は datasheet の範囲外。** 基板側の分圧・保護が
  何をしているかは M5Stack の製品ページを見る必要がある。無印 Unit ADC (U013) は
  [ADS1100](ads1100.md) を載せた別物で、**同じ `0x48` に見えるが基準電圧の考え方が違う**。

## 出典と確度

- レジスタ定義・転送長・タイミング・電気的特性: すべて TI datasheet SBAS276A（Rev.A, 2003-11）。
  [`chips/ads1110.yaml`](../../chips/ads1110.yaml) の `datasheets:` に記録された版と一致する。
- [`profiles/ads1110.yaml`](https://github.com/tanakamasayuki/I2CDeviceDB/blob/38f1d82/profiles/ads1110.yaml) は `evidence.source: datasheet` /
  `confidence: tentative`。`write_len: 1` / `read_len: 3` /
  `read_layout: "2 data bytes msb-first, then the configuration byte"` は上記 p.12 の記述そのもの。
- **未確認**: 実機キャプチャが無い。ST/DRDY が本当に設定レジスタ読み出しで `1` に戻るか、
  `0xFF` パディングの実際、400kHz での動作、General Call への応答は確かめられていない。
- **未調査**: [`scenarios/ads1110/p0.yaml`](https://github.com/tanakamasayuki/I2CDeviceDB/blob/38f1d82/scenarios/ads1110/p0.yaml) は read-only で、
  device-detection / conversion-read / config-byte-read しか行わない。
  ゲイン掃引・データレート掃引・単発変換のトリガは `deferred` に置かれている。
- **datasheet が答えていないこと**: Unit ADC v1.1 (U013-V11) 基板側の入力レンジ・分圧比。
  チップのフルスケール ±2.048V がそのままコネクタの入力レンジになるとは限らない。
