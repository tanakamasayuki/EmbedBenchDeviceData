# ADS1115 — 4ch/2 差動・PGA・コンパレータ付き 16bit ΔΣ ADC

> 内蔵基準・内蔵発振器・入力マルチプレクサ・PGA・デジタルコンパレータを 1 パッケージに収めた
> 16bit ADC。ポインタバイト方式の 16bit レジスタが 4 本あり、ADDR ピン 1 本で 4 通りの
> アドレスを選べる。ADS111x ファミリ（ADS1113 / ADS1114 / ADS1115）の最上位。
>
> **確度**: Texas Instruments の datasheet
> [SBAS444E](https://www.ti.com/lit/ds/symlink/ads1115.pdf)（2009-05 初版 / 2024-12 改訂）に基づく。
> 本文の数値・ビット定義・転送の形はすべてこの文書由来で、**ライブラリ実装から補った箇所は無い**。
> 実測での確認はしていない（`observations/ads1115/` は未取得）。

## これは何か

TI の 10 ピン（X2QFN / SOT / VSSOP）ΔΣ A/D コンバータ。外付けは電源のバイパスコンデンサと
I2C プルアップだけで、基準電圧源も発振器も要らない。ADS1113 / ADS1114 とはレジスタマップを
共有し、**ADS1115 だけが MUX（4 単端 or 2 差動）を持つ**。

できること:

- 4 本の単端入力（AIN0–AIN3 対 GND）、または 2 組の差動入力を MUX で切り替えて測る。
- PGA でフルスケールを ±6.144V / ±4.096V / ±2.048V / ±1.024V / ±0.512V / ±0.256V から選ぶ。
  分解能は常に 16bit なので、LSB は `FSR / 2^16` = 187.5µV 〜 7.8125µV。
- データレートを 8 / 16 / 32 / 64 / 128 / 250 / 475 / 860 SPS から選ぶ。**単サイクル整定**なので
  変換時間は `1 / DR` そのもの。
- ALERT/RDY ピンで、しきい値超過（コンパレータ）または変換完了（RDY）を**ハードウェアで**通知する。
- 単発モードで自動パワーダウンし、デューティサイクル動作で消費を 1/100 程度まで落とす。

できないこと・持っていないもの:

- **外部基準を使えない。** 内蔵基準はバンドギャップではなく、電圧値そのものが規定されていない。
  「基準電圧 × ゲイン」で換算するのではなく、**FSR の表を直接使う**（datasheet §7.3.4, p.15）。
- **負電圧を入力できない。** 絶対入力電圧は GND 〜 VDD の範囲。差動としては双極性を読めるが、
  どちらのピンも GND を割ってはいけない。
- **FSR を選んでも入力保護にはならない。** `±6.144V` を選んでも `VDD + 0.3V` を超える電圧を
  加えてはいけない。VDD=3.3V で `±4.096V` を選ぶと、コード範囲の上のほうが単に使われないだけ。
- 同時サンプリングができない。MUX なので 1 チャンネルずつ順番に測る。
- **ALERT/RDY はオープンドレイン。** プルアップが要る。RDY として使う場合も同じ。
- しきい値レジスタは PGA 設定を知らない。**FSR を変えたら書き直す**必要がある。
- ADS1113 には PGA もコンパレータも MUX も無い（FSR は ±2.048V 固定）。ADS1114 は MUX が無い。

## レジスタ

`profiles/ads1115.yaml` の内容に、datasheet の単位とバイト順を足したもの。
**すべて 16bit・MSB first・2 の補数**（しきい値と変換結果）。

| ポインタ | key | 名前 | R/W | リセット値 | 意味 |
|---|---|---|---|---|---|
| `0x00` | `conversion` | Conversion | R | `0x0000` | 直前の変換結果。16bit 2 の補数 |
| `0x01` | `config` | Config | R/W | `0x8583` | 動作モード・MUX・PGA・データレート・コンパレータ |
| `0x02` | `lo-thresh` | Lo_thresh | R/W | `0x8000` | コンパレータ下限しきい値。16bit 2 の補数 |
| `0x03` | `hi-thresh` | Hi_thresh | R/W | `0x7FFF` | コンパレータ上限しきい値。16bit 2 の補数 |

**転送の形**（datasheet §7.5.2–7.5.3, p.20–21）:

- 書き込み: `START` → アドレス+W → ポインタバイト → データ MSB → データ LSB → `STOP`。
  ポインタバイトの上位 6bit は常に `000000` を書く。
- 読み出し: `START` → アドレス+W → ポインタバイト → `STOP` または repeated `START` →
  アドレス+R → データ MSB → データ LSB。
- **ポインタは保持される。** 同じレジスタを繰り返し読むならポインタの書き直しは不要。
  別のレジスタを読んだあとは書き直す。

### Config レジスタ（`0x01`、リセット値 `0x8583`）

| bit | 名前 | 意味 |
|---|---|---|
| 15 | OS | **書き**: `1`=単発変換を開始（パワーダウン中のみ有効、変換中は無効） / `0`=無効。**読み**: `0`=変換中 / `1`=変換していない。**読み書きで意味が逆向きなので注意** |
| 14-12 | MUX[2:0] | 入力選択。`000`=AIN0−AIN1（既定） / `001`=AIN0−AIN3 / `010`=AIN1−AIN3 / `011`=AIN2−AIN3 / `100`=AIN0−GND / `101`=AIN1−GND / `110`=AIN2−GND / `111`=AIN3−GND |
| 11-9 | PGA[2:0] | FSR。`000`=±6.144V / `001`=±4.096V / `010`=±2.048V（既定） / `011`=±1.024V / `100`=±0.512V / `101`〜`111`=±0.256V |
| 8 | MODE | `0`=連続変換 / `1`=単発変換＝パワーダウン（既定） |
| 7-5 | DR[2:0] | `000`=8 / `001`=16 / `010`=32 / `011`=64 / `100`=128（既定） / `101`=250 / `110`=475 / `111`=860 SPS |
| 4 | COMP_MODE | `0`=従来型コンパレータ（既定） / `1`=ウィンドウコンパレータ |
| 3 | COMP_POL | ALERT/RDY の極性。`0`=アクティブ Low（既定） / `1`=アクティブ High |
| 2 | COMP_LAT | `0`=ラッチしない（既定） / `1`=ラッチする。**ラッチは Conversion レジスタの読み出しか SMBus alert response でしかクリアできない** |
| 1-0 | COMP_QUE[1:0] | `00`=1 回で assert / `01`=2 回 / `10`=4 回 / `11`=コンパレータ無効・ALERT/RDY を Hi-Z（既定） |

リセット値 `0x8583` は「単発モード・パワーダウン・AIN0−AIN1・±2.048V・128SPS・コンパレータ無効」。
**電源投入直後は何も測っていない**。

### ALERT/RDY を変換完了ピンとして使う

- `Hi_thresh` の MSB を `1`、`Lo_thresh` の MSB を `0` にする。
- `COMP_QUE[1:0]` を `11b` 以外にする（`11b` だとピンが Hi-Z のまま）。
- 連続変換モードでは変換ごとに約 8µs のパルスが出る。単発モードでは COMP_POL=0 のとき
  変換終了で Low になる。
- このとき COMP_MODE / COMP_LAT は機能しない（datasheet §7.3.8, p.17）。

### そのほかのバス上の振る舞い

- **General Call に応答する。** アドレス `0000000b` に続けて `0x06` を送るとレジスタがリセットされ、
  パワーダウン状態に入る。
- **Hs モード（3.4MHz）は明示的な起動が要る。** START の後に Hs controller code `00001xxx` を送る
  （ACK されない）。次の STOP で抜ける。
- **バスが 25ms 以上アイドルだとタイムアウトする**（datasheet §7.5.1, p.19）。

## 典型的な使い方

1. **アドレスを決める。** ADDR ピンの配線で `0x48`–`0x4B`。SDA に繋いでアドレスを作る場合は、
   SCL が Low になってから 100ns 以上 SDA を Low に保つ必要がある。
   datasheet は「GND / VDD / SCL を先に使え」と勧めている（§7.5.1.1, p.20）。
2. **Config レジスタを 1 回書く。** MUX・PGA・DR・MODE・コンパレータをまとめて 16bit で設定する。
   単発で 1 回測るなら OS=1 も同じ書き込みに含める。
   例: AIN0−GND、±4.096V、128SPS、単発、コンパレータ無効 → `0xC383`。
3. **待つ。** `1 / DR`（128SPS なら 7.8ms）。単発では起動の約 25µs が加わる。
   データレートには ±10% の振れがあるので、固定待ちなら余裕を持たせる。
4. **完了を確認する（任意）。** Config を読んで bit15（OS）が `1` なら変換は終わっている。
   ALERT/RDY を RDY として配線してあるなら、そのエッジで待つほうが速い。
5. **ポインタを `0x00` にして Conversion を 2 バイト読む。** MSB first、2 の補数。
6. **電圧に直す。** `V = Code × FSR / 32768`。FSR は表から取り、
   基準電圧×ゲインで計算しないこと。
7. 連続変換で使う場合は MODE=0 で書き、以後はポインタ `0x00` のまま 2 バイト読み続ける。
   チャンネルを切り替えるには Config を書き直す。**書き換えた直後の 1 回は旧設定の変換が完了する**。

## 利用上の注意

- **OS ビットは読み書きで意味が逆。** 書くときは `1`=開始、読むときは `1`=変換していない。
  「1 なら忙しい」と読み替えると常に逆になる。
- **リセット直後は単発モード・パワーダウン。** 何も書かずに Conversion を読むと `0x0000` が返り続ける。
  「値が 0 だ」と騒ぐ前に Config を書いたか確認する。
- **FSR を変えたらしきい値レジスタを書き直す。** コンパレータはデジタル比較なので、
  Lo_thresh / Hi_thresh は生のコードで持っている。PGA を変えると同じコードが別の電圧を意味する
  （datasheet §8.1.4, p.27）。
- **COMP_LAT=1 のラッチは read-to-clear。** Conversion レジスタを読むか SMBus alert response を
  投げるまで ALERT/RDY が下がったままになる。読む場所が 2 か所あると、
  片方の読み出しが他方のアラートを消してしまう。
- **ALERT/RDY はオープンドレイン。プルアップが無いと何も起きない。** RDY モードでも同じ。
  ピンを配線していないなら COMP_QUE=`11b` のままにしておく（既定値がそれ）。
- **チャンネル切り替えには時間がかかる。** MUX を変えるには Config を書く必要があり、
  連続変換モードでは「現在進行中の変換は旧設定のまま完了する」。
  4ch を順に読むなら「書く → 1 変換ぶん待つ → 読む」を各チャンネルで繰り返す。
- **`±6.144V` は保護レンジではない。** 入力に `VDD + 0.3V` を超える電圧を加えてはいけない。
  VDD=3.3V の系で 5V の信号を測ろうとして FSR だけ広げるのは誤り。分圧が要る。
- **入力インピーダンスは FSR で 30 倍変わる。** ±0.512V 以下では差動 710kΩ まで下がる。
  高出力インピーダンス源では分圧誤差になる。
- **アドレス衝突。** 本リポジトリ内でも `0x48`–`0x4B` は
  [`ads1100`](ads1100.md) / [`ads1110`](ads1110.md) / `ina226` が名乗り得る。
  `0x48` はさらに `m5stack-mcu-u198`（Unit Step16）とも重なる。
  Unit AMeter (`0x48`) と Unit VMeter (`0x49`) は互いに衝突しないよう ADDR が振り分けてある。
- **AMeter / VMeter は生の ADC コードだけでは電流・電圧にならない。**
  ユニットにはそれぞれ `0x51` / `0x53` に校正値を持つ小さな EEPROM が載っている
  （[`chips/eeprom.yaml`](../../chips/eeprom.yaml)）。**この EEPROM を読まないと換算係数が分からない。**
  M5Stack は EEPROM の型番も校正値のフォーマットも公開しておらず、本リポジトリでは未特定である。
  校正値は**個体ごとに違う**ので、他機の値を流用してはいけない。
- **バスの 25ms タイムアウト。** SCL を長時間止めるデバッガや、遅いソフト I2C で
  トランザクションの途中に長い休止が入ると転送が壊れる。
- **400kHz は datasheet 上は問題ない**（Fast mode 対応、§5.6 にタイミング規格がある）が、
  本リポジトリでは未実測。`scenarios/ads1115/p0.yaml` は 100kHz と 400kHz を試す設定になっている。
